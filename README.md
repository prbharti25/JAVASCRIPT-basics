# JavaScript Basics

A structured collection of JavaScript lessons, exercises, and mini projects created while learning web development.

## About This Repository

This repository follows a practical JavaScript learning path, beginning with the language fundamentals and progressing through functions, objects, the DOM, events, asynchronous JavaScript, and browser-based projects.

## Learning Path

- **Day01-Day06:** Introduction, data types, comparisons, memory management, strings, and math
- **Day07-Day11:** Arrays, dates, objects, and object-oriented practice
- **Day12-Day18:** Functions, conditionals, loops, callbacks, hoisting, global objects, and `this`
- **Day19-Day25:** DOM manipulation, elements, events, forms, and browser interaction
- **Day26-Day27:** Tic-Tac-Toe and astrology projects
- **Day28-Day32:** Callback hell, asynchronous JavaScript, promises, and async/await

## Topics Covered

- JavaScript syntax and data types
- Strings, arrays, dates, sets, and maps
- Objects and object methods
- Functions and callbacks
- Conditional statements and loops
- Scope, hoisting, and memory management
- The global object and the `this` keyword
- DOM selection and manipulation
- Browser events and event propagation
- Form handling and validation
- Callback hell and asynchronous programming
- Promises and async/await

## Projects and Practice

The repository includes hands-on exercises and mini projects such as:

- Tic-Tac-Toe
- Astrology project
- DOM interaction exercises
- Event bubbling and capture demonstrations
- Form projects
- Promise and async/await practice

## How to View the Files

1. Clone the repository:

   ```bash
   git clone <your-javascript-repository-url>
   ```

2. Open the cloned folder in VS Code.
3. Open an HTML file in a browser, or use the Live Server extension when working with browser-based lessons.
4. Run standalone JavaScript files with Node.js when the lesson does not depend on the browser.
